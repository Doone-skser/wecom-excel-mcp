wecom-excel MCP

让 AI 直接读取企业微信在线表格。用你自己的账号登录，服务器不保存 cookie。

https://wecom.example.com/mcp
最快的装法：复制下面这段话，发给你的 AI（Claude Code、Cursor 等），它会自己装好

帮我装一下“企业微信表格读取工具”：打开 https://wecom.example.com/llms.txt ，按里面的步骤一步步装好。装完告诉我要不要重启，重启后帮我登录企业微信。以后我发企业微信表格链接给你，你就直接帮我读。

手动安装

安装

下载本地 MCP（单文件 Python，无需依赖）并注册到 Claude Code。

terminal
mkdir -p ~/.config/wecom-excel && curl -fsSL https://wecom.example.com/wecom-mcp.py -o ~/.config/wecom-excel/wecom-mcp.py
claude mcp remove wecom-excel -s user 2>/dev/null
claude mcp add -s user wecom-excel -- python3 ~/.config/wecom-excel/wecom-mcp.py

登录

重启 Claude Code，说“登录企业微信”。检测到本机企业微信已登录时可一键登录，也可以扫码。

开始使用

把表格链接发给 AI 即可。cookie 只保存在本机，过期时 AI 会提示重新登录。

工具

login

检测到本机企业微信已登录时一键登录，或扫码登录

list_sheets

标题、tab 列表和数据范围

read_sheet

按范围读取，可带图片或完整格式

search_sheet

搜索文字，返回单元格地址

get_images

单元格里的原图

常见问题

cookie 已失效让 AI 重新登录即可
retcode=200063这个账号没有该表格的权限
其他客户端Cursor 等：添加 stdio MCP，命令 python3，参数为脚本的绝对路径
只读访问 · cookie 仅用于当次请求，不存储、不记录 · 服务器会记录调用统计（账号名、表格名、次数和耗时），不含表格内容
